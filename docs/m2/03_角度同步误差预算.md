# M2 角度同步误差预算

## 1. 目标

对当前“单圈换向”双向扫描版本的角度同步链路给出可解释、可量化的误差预算，覆盖：

- 编码器分辨率
- 配对时刻误差
- 转速波动误差
- 机械误差

本页先完成前三项；机械误差作为 M6 后续几何质量测试项延期，不作为 M6 前冻结阻塞项。

## 2. 当前预算假设

### 2.1 编码器参数

当前工程参数：

- `ENC_PPR = 7`
- `GEAR_RATIO = 210`
- 四倍频计数

所以：

```text
counts_per_rev = 7 * 210 * 4 = 5880 count/rev
```

### 2.2 当前闭环工作点

当前双向稳速版本的目标速度幅值为：

- `0.15 rps`
- 即 `150 mrps`

对应角速度幅值：

```text
omega_target = 0.15 * 360 = 54 deg/s
```

本轮用于预算的实测日志为：

- [data/m2_bidirectional_reverse_log.csv](./data/m2_bidirectional_reverse_log.csv)

按稳态样本统计得到：

- 负向稳态最大绝对误差：`13 mrps`
- 正向稳态最大绝对误差：`17 mrps`

为保守起见，本页采用更大的那一个：

```text
speed_deviation_max = ±17 mrps = ±0.017 rps
```

## 3. 分项预算

### 3.1 编码器分辨率误差

单个编码器计数对应角度为：

```text
angle_per_count = 360 / 5880 = 0.061224 deg
```

按半格量化误差预算：

```text
encoder_quantization_error = ±0.061224 / 2 = ±0.030612 deg
```

本页记为：

- 编码器分辨率误差：`±0.0306°`

### 3.2 配对时刻误差

当前点时刻按 UART 帧中心估计：

```text
t_sample_us = frame_end_us - (LUNA_FRAME_LEN * UART_CHAR_US) / 2
```

其中：

- `LUNA_FRAME_LEN = 9`
- `UART_CHAR_US = 87 us`
实现对应关系：

- `LUNA_FRAME_LEN`、`UART_CHAR_US`、`UART_IDLE_GUARD_US` 当前由协议/解析常量统一表达
- 显式 `LunaParseState` 状态机只改变 parser 内部组织方式，不改变成功帧的时间中心估算公式
- checksum 滑动重同步只影响错误帧后的恢复路径；对已经成功校验并输出的点，帧中心时间估算公式不变

因此半帧时间为：

```text
pair_time_uncertainty = 9 * 87 / 2 = 391.5 us
```

在当前目标角速度幅值 `54 deg/s` 下，对应角度不确定度为：

```text
pairing_angle_error = 54 * 391.5e-6 = 0.021141 deg
```

本页记为：

- 配对时刻误差：`±0.0211°`

### 3.3 转速波动误差

当前角度回推使用：

```text
sample_count32 = chunk_encoder_count32 - round(ticks_per_us * dt_us)
```

所以只要从点采样时刻到 chunk 锚点之间存在速度波动，就会带来额外角度误差。

#### 3.3.1 速度波动

根据当前双向稳态日志，保守取：

```text
speed_deviation_max = ±0.017 rps
```

换算成角速度偏差：

```text
omega_deviation = 360 * 0.017 = 6.12 deg/s
```

#### 3.3.2 最坏回推时间

当前 chunk 缓冲上限为 `64 byte`。对一个最早被完整解析的 9 字节帧，保守估计：

- 帧后最多剩余 `55 byte`
- 加 `UART_IDLE_GUARD_US = 87 us`
- 再加半帧时间 `391.5 us`

得到：

```text
dt_backtrack_max = 87 + 55 * 87 + 391.5 = 5263.5 us
```

#### 3.3.3 角度预算

于是速度波动导致的最大角度误差保守估计为：

```text
speed_fluctuation_error = 6.12 * 5263.5e-6 = 0.03221262 deg
```

本页记为：

- 转速波动误差：`±0.0322°`

### 3.4 机械误差

当前冻结口径：

- 固定目标重复定位实测暂不补
- 本轮不填虚构数值
- 机械误差转入 M6 几何质量与重复性测试，不阻塞 M2 在 M6 前冻结

保留项：

- 机械误差：`M6 后续实测`

## 4. 预算汇总表

| 误差源 | 当前估算方法 | 当前预算值 |
| --- | --- | --- |
| 编码器分辨率 | `360 / 5880 / 2` | `±0.0306°` |
| 配对时刻误差 | `54 deg/s * 391.5 us` | `±0.0211°` |
| 转速波动误差 | `6.12 deg/s * 5263.5 us` | `±0.0322°` |
| 机械误差 | 固定目标多圈重复定位 | M6 后续实测 |

## 5. 当前合成结果

在**不计机械误差**的前提下：

### 5.1 RSS 合成

若前三项视为独立，则：

```text
sqrt(0.0306^2 + 0.0211^2 + 0.0322^2) ≈ 0.0492 deg
```

本页记为：

- 非机械项 RSS 合成误差：`约 ±0.0492°`

### 5.2 线性保守上界

若按线性叠加保守估计：

```text
0.0306 + 0.0211 + 0.0322 = 0.0840 deg
```

本页记为：

- 非机械项线性保守上界：`约 ±0.0840°`

## 6. 结论

在当前双向换向版本下，角度同步误差预算已经完成以下三项的正式量化：

- 编码器分辨率误差
- 配对时刻误差
- 转速波动误差

当前延期项为：

- 机械误差实测值

因此，按“M6 前冻结非机械误差预算，机械误差转入 M6 几何质量测试”的口径，本页满足 M2 的 M6 前冻结要求。
