# CAN 报文定义表

这份文档描述当前 MCU 对外发送的 CAN 报文定义，以及 Linux 接收端的重组、超时、覆盖和 `seq` 回绕规则。

## 1. 当前实现快照

当前固件发送两帧标准 CAN 报文。

### 1.1 报文 A

| 项目 | 当前值 |
| --- | --- |
| CAN ID | `0x123` |
| 帧类型 | 标准帧 |
| DLC | `8` |
| 作用 | 发送距离、角度、质量 |

| Byte | 字段 | 编码 |
| --- | --- | --- |
| 0 | `seq` | 1 字节序号 |
| 1 | `distance_cm[15:8]` | 大端高字节 |
| 2 | `distance_cm[7:0]` | 大端低字节 |
| 3 | `angle_deg_bits[31:24]` | `float` 原始位 |
| 4 | `angle_deg_bits[23:16]` | `float` 原始位 |
| 5 | `angle_deg_bits[15:8]` | `float` 原始位 |
| 6 | `angle_deg_bits[7:0]` | `float` 原始位 |
| 7 | `quality` | `uint8_t` |

### 1.2 报文 B

| 项目 | 当前值 |
| --- | --- |
| CAN ID | `0x124` |
| 帧类型 | 标准帧 |
| DLC | `8` |
| 作用 | 发送 MCU 时间、原始角度、状态 |

| Byte | 字段 | 编码 |
| --- | --- | --- |
| 0 | `seq` | 与报文 A 配对 |
| 1 | `t_sample_us[31:24]` | 大端高字节 |
| 2 | `t_sample_us[23:16]` | 大端 |
| 3 | `t_sample_us[15:8]` | 大端 |
| 4 | `t_sample_us[7:0]` | 大端低字节 |
| 5 | `angle_tick[15:8]` | 大端高字节 |
| 6 | `angle_tick[7:0]` | 大端低字节 |
| 7 | `status` | `uint8_t` |

## 2. 已冻结结论

- 距离字段已冻结为 `distance_cm`
- `t_sample_us` 已冻结为 MCU 侧每点时间戳
- `luna_chunk_rx_time_us` 不上 CAN
- `host_rx_time_us` 不上 CAN
- CAN 继续发送 `float angle_deg`
- 多字节整数当前按大端编码
- 两帧通过 `seq` 配对
- `seq` 为 1 字节有效值，取值范围 `0..255`，按 `uint8_t` 自然回绕
- `checksum` / `AMP_LOW` / `TOO_NEAR` 异常帧当前在 MCU 侧直接丢弃，不进入 CAN 输出
- 零位当前冻结为“开机零位”，但零位锁定字段不进入 CAN
- 圈边界当前基于内部 `rev_id` 定义，但 `rev_id` 不进入 CAN 输出
- 链路级丢点当前仅做计数，不做补点、不做重发、不做插值

## 3. Linux 接收端重组规则

- 接收端按 `seq` 重组 `0x123` 与 `0x124`。
- 只有同一 `seq` 的 A 帧和 B 帧都到达后，才输出一个完整点。
- 双帧配对超时固定为 `50 ms`。超过 `50 ms` 仍未配齐的 pending 半帧直接淘汰，并计入 timeout/drop 统计。
- 同一 `seq` 下，如果新的 `0x123` 到达时旧 `0x123` 尚未完成配对，则新帧覆盖旧帧，并计入 `overwrite_a` 统计。
- 同一 `seq` 下，如果新的 `0x124` 到达时旧 `0x124` 尚未完成配对，则新帧覆盖旧帧，并计入 `overwrite_b` 统计。
- `seq` 的 `255 -> 0` 是正常回绕，不视为乱序或丢帧。
- 接收端不补点、不重发、不插值；所有丢帧、超时和覆盖只进入统计摘要，主链路继续运行。

## 4. 风险与说明

| 编号 | 项目 | 说明 |
| --- | --- | --- |
| M1 | 浮点角度上总线 | 跨语言解析和协议兼容成本较高 |
| M2 | 双帧配对依赖 `seq` | 丢任一帧都会导致重组失败 |
| M3 | `seq` 实现为 1 字节有效值 | `255 -> 0` 按正常回绕处理 |

## 5. 与时间戳语义的边界

- `t_sample_us` 表示 MCU 侧每点时间
- `luna_chunk_rx_time_us` 仅用于内部估计，不对外传输
- `host_rx_time_us` 仅在 Linux 侧生成和使用，不属于 CAN 协议字段
- `status` 仅描述成功输出点的状态；被丢弃的异常帧通过内部计数器体现，不通过 CAN 发送
- `g_zero_offset_count32`、`g_last_rev_id`、`g_rev_transition_cnt` 属于 MCU 内部状态，不属于 CAN 协议字段
