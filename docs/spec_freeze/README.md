# 规格冻结交付物

这组文档用于把当前实现、字段语义和对外接口冻结下来，避免后续继续出现“代码里一种叫法、文档里另一种叫法”的情况。

建议写法：

- 主文档使用 Markdown：适合版本管理、评审、和代码一起维护。
- 表格仍写在 Markdown 里：先冻结语义，再决定是否导出为 CSV 或 Excel。
- 如果后续需要给非研发同学正式流转，再从 Markdown 导出为 PDF 或 XLSX。

当前已识别的命名/语义风险：

- 主距离字段已冻结为 `distance_cm`，后续文档和上位机字段不得再引入 `distance_mm`。
- `t_sample_us` 在草案里表示“采样或配对时间”，需要冻结成唯一含义，不能同时表示“串口到达时间”。
- `host_rx_time_us` 是 Linux 侧接收时间，不能与 MCU 侧时间戳混用。
- `angle_tick` 是原始编码器计数，`angle_deg` 是派生量，两者应同时保留但职责不同。

建议冻结原则：

- 内部采样时间与主机接收时间分离命名。
- 原始量与派生量分离命名。
- 单位只保留一种主单位，另一种作为派生列或显示层转换。
- 文档里必须区分“当前实现”与“冻结结论”。
