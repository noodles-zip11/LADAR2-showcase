# LADAR2 简历版项目条目

## 项目名称

基于 STM32F407 与 CAN 的旋转式 2D LiDAR 感知系统

## 简历条目

- 基于 STM32F407、FreeRTOS、TF-Luna、编码器电机和 CAN，完成旋转式 2D LiDAR 感知链路，实现 LiDAR 采集、角度/时间配对、CAN 双帧传输、上位机重组、CSV 记录、历史回放和 2D 点云显示。
- 设计并冻结 MCU/CAN/CSV 数据合同，区分 `t_sample_us` 与 `host_rx_time_us` 语义，定义距离、角度、质量、状态、序号和时间戳字段，降低固件、上位机和离线分析之间的字段漂移风险。
- 实现 TF-Luna UART DMA + IDLE 接收与解析状态机，补充 checksum 失败、错帧、噪声前缀、分片帧和恢复路径的 host selfcheck，提高传感器输入链路的可观测性和鲁棒性。
- 实现 CAN 双帧点数据协议与上位机重组逻辑，补齐 ACK fault recovery、重组超时、覆盖、`seq` 回绕和诊断统计证据，形成可回溯的通信异常处理闭环。
- 构建 Python 上位机工具链，支持 live CAN、CSV replay、点云显示、扇区摘要、状态面板、告警输出、CSV/log/MQTT 可插拔输出适配器，并完成本地 Mosquitto + Windows 上板 MQTT 最小闭环验证。
- 完成短长稳与几何质量基线验证：约 1h42min 连续运行，采集 612466 点，CAN 重组丢包率 0.001143%；墙面直线 RMSE 7.44 mm，箱体重复性 p95 约 20.00 mm。
- 建立 M8 数据闭环：将有效 CAN CSV 归档为 replay 数据集，生成标签模板和离线分析报告；M9 仅保留为附录性质的 rule-based 质量门骨架，不作为核心效果证明。
- 输出 README、系统框图、数据流图、时序图、协议表、字段表、测试记录、项目总览和面试讲稿，明确 V1 边界：不夸大 4h 长稳、完整 Bus-Off、云端平台、ESP32 或 AI 模型能力。

## 口语压缩版

我做的是一个基于 STM32F407 和 CAN 的旋转式 2D LiDAR 感知项目。MCU 侧接收 TF-Luna 数据，结合编码器和电机状态估算点的采样时间与角度，再通过双帧 CAN 协议发给上位机；上位机负责点重组、CSV 记录、实时/回放点云显示和离线分析。项目重点不是单次演示，而是把字段合同、时间戳语义、诊断统计、自检、长稳基线和几何质量证据都收口成可复现的工程闭环。

## 注意边界

- 不写“严格 4h 长稳已通过”，当前证据是约 1h42min 短长稳基线。
- 不写“完整 Bus-Off 已验证”，当前证据是 ACK fault recovery。
- 不把 MQTT、云端、ESP32 或 AI 模型写成 V1 主体能力。
- M9 当前只是附录和后续扩展入口，不作为简历主亮点；不要写 precision/recall 或异常检测效果。
