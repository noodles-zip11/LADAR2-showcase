# LADAR2 一页项目总览

## 项目定位

LADAR2 是一个旋转式 2D LiDAR 感知系统，重点放在感知链路和通信链路：LiDAR 采集、电机角度同步、CAN 传输、上位机点云重组、CSV 记录、历史回放、可视化和验证。

V1 阶段不把项目包装成云端产品。第一阶段的核心是 CAN、本地上位机工具和可复现证据。

## 系统组成

| 层级 | 组件 | 职责 |
| --- | --- | --- |
| 传感/机械层 | TF-Luna、电机、编码器、旋转结构 | 产生距离样本和物理扫描角度 |
| MCU 固件层 | STM32F407、FreeRTOS、UART DMA、TIM 编码器、CAN | 解析帧、估算点时间/角度、发送点数据 |
| 上位机工具层 | Python、python-can、PySide6/pyqtgraph、CSV、回放 | 接收、重组、存储、显示、回放、分析 |
| 可选扩展层 | MQTT 适配器 | 发布 telemetry/status/alarm，用于本地插件阶段集成 |

## 关键设计点

- LiDAR 输入使用 USART2 DMA + IDLE，避免接收阻塞解析任务。
- TF-Luna parser 拆分为帧头搜索、checksum 校验、解码、过滤和输出路径。
- 角度同步基于编码器计数、电机速度估计和 UART chunk 时间锚点。
- 每个点拆成两帧标准 CAN 报文：`0x123` 和 `0x124`，通过 `seq` 配对。
- 上位机冻结 CSV 字段，让实时数据、回放和离线分析使用同一份契约。
- M6 几何分析不修改原始 CSV；过滤只放在分析/显示层，不回写固件输出。

## 验证结果

| 方向 | 结果 |
| --- | --- |
| 上位机闭环 | 实时/回放 CAN 接收、CSV、2D 点云显示已完成 |
| 长稳基线 | 约 `1h42min`，`612466` 点，CAN 重组丢包率 `0.001143%` |
| 几何基线 | 墙面 RMSE `7.44 mm`；盒子重复性 p95 `20.00 mm`；闭合缝隙 `11.82 mm` |
| 诊断 | ACK fault recovery 证据已归档；Bus-Off 保留为后续更强故障注入 |
| MQTT 插件范围 | 本地 broker、回放、Windows 上板 telemetry/cmd/status/alarm 已验证 |

## 关键难点

- 距离样本和角度样本不是同一个硬件事件产生的，所以必须明确时间戳和角度语义。
- 标准 CAN 载荷很小，一个点必须拆成两帧并可靠重组。
- 上位机接收时间不能当成测量时间。
- 几何质量不仅取决于固件同步逻辑，也受传感器近场限制、安装偏心、目标摆放、过滤和显示连线策略影响。
- 长稳结论必须区分“已经测到的事实”和“仍然是目标的指标”。

## V1 边界

V1 包含本地端到端感知链路和验证材料。不包含 ESP32、云端上传、TLS/auth、量产外壳、完整 Bus-Off 注入证明，也不包含严格 4h 长稳通过，除非后续重新跑并归档。

## 推荐面试概述

我做的是一个基于 STM32F407 和 CAN 的旋转式 2D LiDAR 感知链路。MCU 解析 TF-Luna 数据，把每个距离值和估算采样时间、编码器角度配对，通过固定双帧 CAN 报文发给上位机；上位机重组点云，保存 CSV，并支持实时显示和历史回放。我重点做了工程收口：字段冻结、时间戳语义、诊断、自检、长稳基线、几何指标和清楚的 V1 边界。
